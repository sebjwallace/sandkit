What carries these tags?

The tags engine at work on the discovery demo's records. Choose tags with + (must carry) and − (leave out), or start from a preset. Each result's score, from 0 to 1, is how much of the weight of its tags it shares with what you chose, and rarer tags weigh more. A score says where to look first, never what's true. An agent asking the same with tags.mjs search gets the same results, in the same order.
