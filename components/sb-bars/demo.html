A set of things compared on one measure, with how each moved since the last update.

About

Often the question isn't how one thing changes over time, but how several things compare right now: which store is lowest on stock, which category is over budget, which town has the most rain. Bars put them side by side on one scale, so the longest and shortest stand out at once. When the model moves on, each bar shows how far it moved, with a faint mark where it was.

Where it helps

  • Finding the biggest and the smallest. Sort the bars and the answer is at the top.
  • Seeing who's past a line. A reorder level, a budget, a safe limit, drawn across every bar.
  • Watching a step's effect across many things. Each bar says which way it moved, and whether that's good.

Where something else fits better

  • Change over time. A line chart shows the history of one or two things.
  • Several measures for each thing. A table compares many columns at once.
  • One or two numbers. Headline figures say it more plainly.

Getting started

<script src="components/sb-bars/sb-bars.js"></script>
<sb-bars sort="descending" better="higher"></sb-bars>

<script>
  const bars = document.querySelector('sb-bars');
  bars.lines = [{ value: 40, label: 'Reorder', tone: 'warn' }];
  // Whenever the model changes:
  bars.bars = model.stores.map((s) => ({ id: s.id, label: s.name, value: s.stock }));
</script>

Set the bars again whenever the model changes; each bar with an id shows how it moved. Say whether higher or lower is better so the changes read as good or bad news. Negative values grow to the left of zero.

Making it reveal, not just display

  • Draw the line that matters, such as a limit or a target, so each bar answers "is this all right?"
  • Sort when the ranking is the point; keep a fixed order when people need to find the same bar each time.
  • Use tone for bars past a threshold, and only those.
  • Point at bars from the prose with highlight, so a sentence about one store lights its bar.

Examples

Stock across a chain of shops

Each day every shop sells some stock, and any shop below the reorder level gets a delivery the next morning. Watch which shops dip, and which recover. The harbour shop is the busiest.

Over or under budget

How much is left in each part of a month's budget, as columns; below zero is overspent. The names are too long to fit under the columns, so each has a number and a legend names them: point at either. Spend more on eating out and watch it slide past zero, while the fixed costs stay put.
