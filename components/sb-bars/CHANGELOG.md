# sb-bars changelog

## 0.1.0 · 2026-10-17
- First release. Bars on one scale, across or (`orientation="vertical"`) up as columns, with a numbered legend when column labels don't fit; negatives growing away from zero, optional sorting and reference lines; each bar's change since the last update shown with a mark where it was, coloured by which way is better; tones, highlighting and selection.
