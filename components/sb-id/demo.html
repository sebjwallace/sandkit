A short identifying code that explains itself.

About

Sandboxes are explored by several people and agents at once, and they need to be sure they are talking about the same thing. A short code such as RUL-001 means exactly one thing to everyone. sb-id shows that code as a small pill that explains itself on hover, and lights up every other mention of it when clicked, so a reader can see at a glance where a rule or a claim matters.

Where it helps

  • Citing rules and evidence in prose. Chapter text that says why something happens can point to exactly which rule or source says so.
  • Tracing behaviour. Highlight a code, and see every panel and paragraph it touches.
  • Talking about the sandbox. People and agents can refer to "RUL-001" in conversation, and anyone can find it.
  • Finding broken references. A code nothing defines shows as dashed, so gaps are visible rather than hidden.

Where something else fits better

  • Things nobody will refer to. Momentary details, such as a single step of a simulation, don't need codes. Too many pills become noise.
  • Long explanations. The card is for a sentence or two. Put fuller explanations in the page, and cite the code there.

Getting started

<script src="components/sb-id/sb-id.js"></script>
<p>Stores reorder when stock runs low (<sb-id code="RUL-001"></sb-id>).</p>

<script>
  // One listener answers for every pill, from the sandbox's own model.
  document.addEventListener('sb-resolve', (e) => {
    const rule = model.rules.find((r) => r.id === e.detail.code);
    if (rule) e.detail.definition = { kind: 'Rule', title: rule.title, description: rule.description };
  });
</script>

Making it reveal, not just label

  • Issue codes in the model first, then cite them everywhere the thing appears. A code that only exists in the interface traces nothing.
  • Show names and codes together where there is room: "Store North ". The name is for reading, the code for referring.
  • Cite the rule where behaviour happens. "Ordered 63 because of RUL-001" lets a reader follow cause to rule in one click.

Before choosing codes for a sandbox, read the identifiers practice. The full contract is in the manifest.

Examples

A supply chain

Rules and locations, cited in prose. Hover a pill to see what it is; click one to light up every mention.

Each store follows the reorder rule : when stock plus deliveries on the way falls below its reorder point, it orders back up to its target from the distribution centre . The distribution centre follows the same rule with its suppliers, alternating between them .

Store North sells the most, so it reaches its reorder point first .
