# sb-plane changelog

## 0.1.2 · 2026-10-25
- Manifest: names no other component, not even as a suggestion. Which components go together is for the practices.

## 0.1.1 · 2026-10-17
- Added: a `highlight` property, a list of object ids to light up (thicker arrows, larger points, fuller shapes), for pointing at objects from elsewhere in the sandbox.

## 0.1.0 · 2026-10-17
- First release. A two-dimensional coordinate plane with vectors, points and polygons, transformed smoothly by a matrix as progress goes from 0 to 1, with the basis vectors on request and draggable, snappable tips.
