Nested things, as in a file system or an outline, opened and closed by viewers and by the sandbox alike.

About

Many subjects are things inside things: folders in folders, chapters in a book, teams in a company, species in a family. A tree shows that nesting, with lines joining each thing to the one it belongs to. Branches open and close, so people can look at the part they care about and fold the rest away. Anything a viewer can do, the sandbox can do too: open the way to something, select it, or point at it.

Where it helps

  • Finding your way around a hierarchy. A file system, an organisation, a classification, the parts of a machine.
  • Showing where something lives. The sandbox can open the way to a node and select it, so "where is this?" gets a visible answer.
  • Pointing into hidden places. A highlighted node inside a closed branch marks the branch, so you can see where to look.

Where something else fits better

  • Things with several parents, or cross-links. A tree gives each thing one place. Use a graph when things connect more freely.
  • Comparing many things on several measures. A table lines them up; a tree only nests them.
  • A shallow list. One level of nesting rarely needs a tree.

Getting started

<script src="components/sb-tree/sb-tree.js"></script>
<sb-tree></sb-tree>

<script>
  const tree = document.querySelector('sb-tree');
  tree.nodes = [
    { id: 'docs', label: 'Documents', children: [
      { id: 'cv', label: 'CV.pdf', meta: '120 KB' }
    ] }
  ];
  tree.reveal('cv');      // open the way to it
  tree.selected = 'cv';
</script>

A node with children is a branch, even with none yet. Give it meta for a quiet detail on the right, such as a size or a count, and a tone where it deserves attention. Viewers click the arrow to open a branch, and the row to select it, or use the arrow keys.

Making it reveal, not just display

  • Open the way to what matters. When the model does something to a node, reveal it, so people see where in the hierarchy it happened.
  • Point from the prose. Set highlight when a sentence mentions a node; if it's folded away, its branch is marked.
  • Put the telling number in meta, such as a size or a count, so a glance down the tree compares them.
  • Connect it. Listen for sb-select to show the chosen node's details elsewhere in the sandbox.

The full contract, including every property, method, event and styling hook, is in the manifest.
