One source, with the passages the model cites marked where they are.

About

A sandbox is only as trustworthy as what it's built from. When a rule says "reorder below forty", someone will ask: says who? This component answers by showing the source itself, the interview, the policy, the plan, with the very words the rule rests on marked. The source sits on its own sheet of paper, apart from the card of what's known about it, so it always reads as the ground truth rather than more of the sandbox.

Where it helps

  • Checking a claim. Point at a rule and see the words it came from; judge for yourself whether they say what the model says.
  • Catching drift. A citation whose quote is no longer in its source is listed in red, not hidden. Models change and sources get corrected; this is where the gap shows.
  • Long material. Interviews and documents fold down to the lines that are cited, so the part that matters is in front of you, with the rest a click away.
  • Gathering evidence. Select words, drag across an image, or name a PDF passage, and the sandbox hears which passage someone means, ready to cite or comment on.

Where something else fits better

  • The sandbox's own explanations. Text written for the sandbox, with notes on its phrases, belongs in an annotated passage, not on paper: it isn't a source.
  • Reading data closely. To explore a data set's shape, or walk a JSON document by its paths, use a component made for that; this one shows data as the file it is.
  • A whole library of sources. Show one source at a time here, and choose it from a list or search elsewhere.

Getting started

<script src="components/sb-source/sb-source.js"></script>
<sb-source></sb-source>

<script>
  const view = document.querySelector('sb-source');
  view.source = catalogue.sources.find((s) => s.id === 'SRC-3');
  view.content = await (await fetch(view.source.path)).text();
  view.passages = [{ id: 'RUL-014', quote: 'we reorder as soon as we drop under forty' }];
</script>

The page loads the file, which needs the sandbox served; the component never fetches. Give images and PDFs as url instead of content. Keep sources in a catalogue and cite them from the model, as the sources practice describes. The manifest has the full contract.

Making it reveal

  • Connect it both ways. List what cites the source beside it: pointing at an item lights its words, and pointing at the words lights the item.
  • Go to what's being discussed. Set current when someone asks about a rule, so the source opens at its words.
  • Leave the broken citations in. A quote that isn't found is a finding: fix it in the model, never by hiding it.
  • Keep the details honest. Status, stance and author tell people how far to trust a source; fill them in when cataloguing, and mark a source reviewed once a person has checked it.
