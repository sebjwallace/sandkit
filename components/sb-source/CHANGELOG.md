# sb-source changelog

## 0.1.1 · 2026-10-19
- JSON shows exactly as the file is, no longer re-laid out, so a quote copied from it is in the file and the sources check agrees. HTML is set in fixed-width type, as code.
- Folding keeps every less indented line above a passage too, so a field in JSON or YAML keeps the structure it sits in.

## 0.1.0 · 2026-10-19
- First release. One source as a sheet of paper, apart from a card of its details (format, author, dates, status, stance, role, sensitivity, links), with the passages the model cites marked where they are and quotes it can't find listed. Text, Markdown (lightly styled, its marks kept), data and code, images with region boxes, and PDFs in the browser's viewer at the cited page. Long text folds to the cited lines, with Show all; full screen; pointing, `highlight` and `current`; naming a passage by selecting words, dragging across an image or typing a quote for a PDF.
