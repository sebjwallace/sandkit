# sb-image changelog

## 0.1.2 · 2026-10-25
- Manifest: names no other component, not even as a suggestion. Which components go together is for the practices.

## 0.1.1 · 2026-10-18
- Marks carry `data-ref` beside `data-id`, and `reveal(id)` glides to a mark, saying whether there is one, for the locating practice.

## 0.1.0 · 2026-10-17
- First release. An image from a file or the web, starting on a view that crops it without cutting it; zooming with buttons, Ctrl-scroll and the keyboard, and panning by dragging, always back to the start in one press; boxes and pins with labels and tones; highlighting that glides to a mark and dims the rest; clicks reported as places on the image.
