An image to zoom and pan, starting on the part that matters, with marks that the words around it can glide to.

About

A picture often holds much more than the sentence beside it is about: a whole site plan when the paragraph means one building, a whole board when it means one chip. This component starts on just the part that matters, as if the image had been cropped, while keeping all of it inside. Boxes and pins mark the things being discussed, and highlighting one glides the view there and dims everything else, so the words can steer the eye around the picture. Viewers can always zoom out, pan around, and come back.

Where it helps

  • Explaining something in a picture. A map, a plan, a photograph, a scan, a screenshot: prose points at its parts and the image goes to each in turn.
  • Showing part of a large image. Start on the region the page is about, without cutting a new image, and let curious viewers explore the rest.
  • Placing things on an image. Clicking reports where, as fractions of the image, so marks and views are placed by pointing rather than guessing.

Where something else fits better

  • Things the model draws itself, such as a network or a grid of cells. A component that draws them can light up their real parts, not just boxes over a picture.
  • A coordinate system to work in. A plane with axes suits vectors, points and shapes.
  • A small picture that needs no exploring. A plain <img> is simpler.

Getting started

<script src="components/sb-image/sb-image.js"></script>
<sb-image src="images/site-plan.png" alt="The site plan"></sb-image>

<script>
  const image = document.querySelector('sb-image');
  image.view = { x: 0.2, y: 0.1, w: 0.5, h: 0.4 };       // start here: fractions of the image
  image.marks = [
    { id: 'pump', x: 0.31, y: 0.22, w: 0.08, h: 0.06, label: 'Pump house' },   // a box
    { id: 'gate', x: 0.62, y: 0.35, label: 'Gate', tone: 'warn' }             // a pin
  ];
  image.highlight = 'pump';                                // glide there; null comes back
</script>

The image can be a file in the sandbox's folder or an address on the web. Everything is placed in fractions of the image, from 0 to 1 across and down, so it still lines up if the image is swapped for a sharper copy. To find a place, click it: sb-point reports where. Viewers zoom with the buttons, or Ctrl-scroll and pinch; they pan by dragging, and the circling arrow brings them back.

Making it reveal, not just display

  • Start on what the page is about. Set view to the part the paragraph discusses, rather than shrinking the whole image to fit.
  • Let the words point. Route pointing at a word to highlight, so reading a sentence shows its subject, lit, with the rest dimmed.
  • Mark few things. Each mark should be something the prose talks about; tone the ones that are good or bad news.
  • Connect it. Listen for sb-select to explain a clicked mark elsewhere in the sandbox.
