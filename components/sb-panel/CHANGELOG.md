# sb-panel changelog

## 0.1.4 · 2026-10-25
- Manifest: names no other component, not even as a suggestion. Which components go together is for the practices.

## 0.1.3 · 2026-10-18
- A panel with the `hidden` attribute is hidden; its own display style no longer overrides it.

## 0.1.2 · 2026-10-18
- Added `reveal(ref, place)`: expands a collapsed panel holding a part, and brings it to the front, quietly (see the locating practice).

## 0.1.1 · 2026-10-17
- A panel moved by another element while the page loads is built once, not twice.

## 0.1.0 · 2026-10-17
- First release. Wraps any content in a panel that viewers can pop out into a floating window, drag, resize, collapse, make full screen, and dock back; remembered per viewer when it has an id.
