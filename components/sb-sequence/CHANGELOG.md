# sb-sequence changelog

## 0.1.1 · 2026-10-18
- Participants, and messages and notes given an `id`, carry `data-ref` with it (participants had an undocumented `data-participant-id`), so a sandbox can find them on the page.

## 0.1.0 · 2026-10-17
- First release. Participants with lifelines, calls, replies, asynchronous messages, messages to oneself and notes, spaced to fit their labels, optionally numbered; the current message marked and later ones faded, highlighting and pointing that light what's connected (a participant's messages, a message's participants), and selection.
