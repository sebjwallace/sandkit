The knobs people turn to see what happens.

About

The quickest way to understand a model is to change something and watch what follows. "What if demand doubled?" "What if gravity were weaker?" sb-parameters gives a sandbox its knobs: a labelled slider for each value people can change, showing the value live. It also keeps track of the baseline, marking anything that has moved from its default, so explorers always know how far they are from where they started and can return in one click.

Where it helps

  • Asking "what if?" Push a value and watch the model respond, while it runs.
  • Finding where things break. Slide until behaviour changes character: stock runs out, a queue overflows, a ball stops bouncing.
  • Comparing against a baseline. Changed values are marked with their defaults, so differences are never hidden.

Where something else fits better

  • Values people shouldn't change. Fixed facts of the model belong in its description, not on a slider.
  • Long lists of settings. A dozen sliders overwhelm. Choose the few that teach the most, and leave the rest fixed.
  • Choices that aren't numbers. This first version handles ranges. Toggles and choices will come when a sandbox needs them.

Getting started

<script src="components/sb-parameters/sb-parameters.js"></script>
<sb-parameters></sb-parameters>

<script>
  const parameters = document.querySelector('sb-parameters');
  parameters.definitions = [
    { key: 'demand', label: 'Customer demand', min: 0.5, max: 2.5, step: 0.1, value: 1, unit: '×' }
  ];
  parameters.addEventListener('sb-change', (e) => model.setOption(e.detail.key, e.detail.value));
</script>

Making it reveal, not just control

  • Choose ranges that reach interesting territory. Let people push far enough to see the model change behaviour, not just shift slightly.
  • Set honest defaults, and say where they come from when it matters. Anything placed in a parameter's slot sits beside its name: a note, or a code citing the source.
  • Make the effect visible straight away. Pair the parameters with a chart, a simulation or a count that responds as people slide.
