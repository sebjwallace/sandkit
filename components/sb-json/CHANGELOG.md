# sb-json changelog

## 0.1.1 · 2026-10-19
- A note shows in a card just above the line pointed at or focused, over the page, rather than under the bar, so the code no longer jumps while pointing. It no longer stays on show for the selected path; `sb-select` still carries it.

## 0.1.0 · 2026-10-17
- First release. JSON printed cleanly with line numbers and colours; a spotlight that folds away everything but the paths that matter, with gaps that unfold and a toggle to show it all; a path bar showing the line pointed at or selected, with the sandbox's note for it; highlighting that marks folded gaps; selection, events and keyboard.
