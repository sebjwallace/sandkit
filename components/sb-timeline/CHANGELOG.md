# sb-timeline changelog

## 0.1.1 · 2026-10-18
- Events carry `data-ref` beside `data-id`, and lane labels carry it with the lane's id, so a sandbox can find them on the page.

## 0.1.0 · 2026-10-17
- First release. Moments and spans in lanes, sharing out rows so labels never overlap; a now line fading what hasn't happened yet, and showing how far along a running span is; zooming and panning, with `view` gliding to a stretch; a scrubbable now line that asks the sandbox to move it; selecting, pointing and highlighting of events and lanes.
