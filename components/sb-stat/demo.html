The few numbers that matter, with how they just changed and whether that's good.

About

Most models have a handful of numbers that say how things are going: money left, people ill, stock on the shelves. Headline figures put those up front, large and plain, so they can be read at a glance. Each time the model moves on, each figure shows how it changed and whether that's good news, so the numbers tell a story rather than just sitting there.

Where it helps

  • Keeping score. The few outcomes people care about, above everything else in the sandbox.
  • Seeing the effect of a change. Move a slider or take a step, and each figure says which way it went.
  • Progress towards a goal. Give a figure a maximum and a target, and a bar shows how close it is.

Where something else fits better

  • How a number got here. A chart shows the history; a figure shows only now and the last step.
  • Many things on the same measure. Twenty stores' stock is a table, or bars.
  • Numbers that need explaining. Put them in a sentence, with the reason.

Getting started

<script src="components/sb-stat/sb-stat.js"></script>
<sb-stat></sb-stat>

<script>
  const stats = document.querySelector('sb-stat');
  function show(model) {
    stats.stats = [
      { id: 'stock', label: 'Stock', value: model.stock, max: 100, target: 40, better: 'higher' },
      { id: 'cost', label: 'Cost so far', value: model.cost, format: (v) => `£${v}`, better: 'lower' }
    ];
  }
</script>

Call it every time the model changes. Each figure with an id compares itself with last time and shows the change. Say whether higher or lower is better, and the change is coloured as good or bad news.

Making it reveal, not just display

  • Choose three to five figures. The ones that answer the sandbox's question, not every number the model has.
  • Always say which way is better, so a rise in cases reads as bad and a rise in savings as good.
  • Give targets where there are targets, so "37" becomes "37, short of 40".
  • Use tone for thresholds crossed, such as hospital beds running out.
