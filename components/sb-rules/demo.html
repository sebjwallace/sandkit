The rules a model follows, with the one that applies lit up.

About

Most models come down to rules: when this, do that. Written down, rules are easy to read and hard to follow, because you can't see which one matters at any moment. sb-rules shows a model's rules as a table and lights up the one about to apply, with the one that just applied marked beside it. As the model runs, the highlight moves, and the connection between rules and behaviour becomes something you can watch.

Where it helps

  • Machines that follow a program. Turing machines, cellular automata, protocols: step through and see each rule take its turn.
  • Decisions. Policies, eligibility rules, a thermostat: change the situation and see which rule decides.
  • Finding gaps. A situation where no rule lights up is a gap in the rules, made visible.

Where something else fits better

  • Rules that interact in a web. When the point is how rules lead into one another, a graph shows the structure better.
  • Hundreds of rules. Show the part that matters to the chapter, or group them so the table stays readable.

Getting started

<script src="components/sb-rules/sb-rules.js"></script>
<sb-rules></sb-rules>

<script>
  const rules = document.querySelector('sb-rules');
  rules.columns = [{ key: 'when', label: 'When' }, { key: 'then', label: 'Then' }];
  rules.rules = [{ id: 'RUL-001', when: 'Stock below 40', then: 'Order up to 100' }];
  rules.active = 'RUL-001';
</script>

Making it reveal, not just list

  • Keep active and fired in step with the model. The highlight is the point; a table that never changes is just a list.
  • Give rules stable codes, so the table, the explanation and the log can all point at the same rule.
  • Group by what changes least, such as a machine's state, so people find the rule that applies at a glance.

The full contract is in the manifest.

Examples

A machine that adds one

A Turing machine adding one to a binary number. It runs right to the end of the number, then carries back to the left. Step through and watch which rule applies.

A thermostat's decisions

Decision rules rather than a program. Move the temperature and see which rule decides what the heating does.
