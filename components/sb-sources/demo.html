A sandbox's source material, as cards of paper to search, filter and sort.

About

Every sandbox rests on material someone gathered: interviews, documents, data, notes, and the sandbox's own analyses of them. This component lays all of it out as cards of paper, each saying who wrote it, when, and how far it has been checked, so people can see what the sandbox knows before trusting what it shows, and choose a source to read.

Where it helps

  • Seeing the shape of the evidence. The counts beside each filter say at a glance whose voices the sandbox rests on, how much is speculation, and how much a person has reviewed. Five sources from one author is a finding.
  • Finding the right source. Search, filter by author or stance, narrow to a stretch of dates, and sort, to find the interview or document someone is asking about.
  • Keeping track of change. A replaced source stays, faded, saying what replaced it, so a citation of the old one can still be followed and checked.
  • Seeing what's waiting. Files dropped into the sources folder but not yet catalogued are listed apart, so nothing new goes unseen.

Where something else fits better

  • Reading one source. Open it in a component that shows the source itself, with the passages the model cites marked.
  • Other lists of things. Anything that isn't source material belongs in a general table, which sorts and filters any rows.
  • Tracing a claim. To follow a rule back to the passages it rests on, trace it through the model's items rather than browsing here.

Getting started

<script src="components/sb-sources/sb-sources.js"></script>
<sb-sources></sb-sources>

<script>
  const list = document.querySelector('sb-sources');
  list.catalogue = (await (await fetch('sources/catalogue.json')).json()).sources;
  list.files = await (await fetch('/_sandkit/files?dir=sources')).json();
  list.addEventListener('sb-open', (e) => showSource(e.detail.id));
</script>

The page loads the catalogue, which needs the sandbox served; the component never fetches. The file list is optional. Keep the catalogue as the sources practice describes. The manifest has the full contract.

Making it reveal

  • Catalogue honestly. Stance and status are what make the counts mean something: mark guesses as speculative or assumptions, and a source reviewed only once a person has checked it.
  • Catalogue the sandbox's own analyses with what they were derived from, so "Primary only" separates what people said from what was made of it.
  • Connect it. Open the chosen source beside the list, and light a source's card when its code is pointed at anywhere in the sandbox.
  • Leave replaced sources in. A correction is a new source; the old one stays to show what changed.
