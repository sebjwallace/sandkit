Where something in the model comes from, and what a source shaped.

About

Every rule, figure and assumption in a model, and every button on a screen designed from it, should lead back to the words it rests on. This component draws that chain as one graph flowing left to right: the sources and what was derived from them, the items resting on them, the thing being traced in the middle, and everything resting on it to the right. Sources are paper, so ground truth always looks like ground truth.

Where it helps

  • "Why is that there?" Trace a button, a rule or a number and see the reasoning behind it, all the way to the interview or the standard.
  • "What would this change?" Trace a source and see everything it shaped: if it turns out wrong, this is what needs another look.
  • Finding weak spots. An item resting on nothing cited, an id the model doesn't have, a loop in the reasoning: each is drawn where it is, so gaps in the evidence show up rather than hide.
  • Separating evidence from interpretation. An analysis derived from two sources sits between them and what cites it, so people see what was said and what was made of it.

Where something else fits better

  • Reading a source. Open it in a component that shows the source itself, with the passages marked.
  • Browsing all the material. A list of the catalogue suits that; a trace is for one thing at a time.
  • Where something appears on the page. A cross-reference lists every place a code shows up; a trace shows what it rests on.

Getting started

<script src="components/sb-source-trace/sb-source-trace.js"></script>
<sb-source-trace></sb-source-trace>

<script>
  const trace = document.querySelector('sb-source-trace');
  trace.items = model.items;
  trace.catalogue = catalogue.sources;
  trace.subject = 'SCR-3';
  trace.addEventListener('sb-open', (e) => openSource(e.detail.id));
</script>

Items cite passages and rest on other items, as the sources practice describes. The page loads the catalogue, which needs the sandbox served. To draw the nodes the way the rest of the sandbox draws its things, give drawNode an element for each; the trace still does the tracing. The manifest has the full contract.

Making it reveal

  • Open it from anywhere. A trace mode, where clicking any part with a code opens its trace in a modal, turns the whole sandbox into something people can question.
  • Open sources with every passage marked, so a click on a sheet of paper lands on the very words.
  • Leave the gaps in. Cite nothing rather than cite loosely: an item marked "Nothing cited" is an honest finding, and a question to take back to the people who know.
  • Keep items small. Many small items, each resting on a few others, make traces people can follow.
